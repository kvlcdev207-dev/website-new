# Kathmandu Valley Leo Club Website

Rebuild of kvlc.pcampus.edu.np — a website for campus students: club info,
social work year by year, the committee, and a literature section (poems,
stories, blogs in English and Nepali).

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Commands

- `npm run dev` — run locally
- `npm run build` — production build check
- `npm run lint` — code style check

See PLAN.md for the full project plan and AGENTS.md for the working spec.
